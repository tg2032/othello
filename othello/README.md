# オセロ（Othello / Reversi）

ブラウザで遊べるオセロ。スマートフォンのタッチ操作に対応しています。

## 遊び方

静的ファイルだけで動くので、どちらかの方法で開きます。

- **そのまま**: `index.html` をブラウザで開く
- **ローカルサーバ**（推奨・PWAアイコン等も含めて確実）:

  ```bash
  # 例: プロジェクトのルートで
  npx serve .
  # → http://localhost:3000/othello/index.html
  ```

## 機能

- **CPU戦**（やさしい / ふつう / むずかしい）— 位置評価＋モビリティ＋αβ探索。「むずかしい」は空き13マス以下で完全探索
- **2人対戦**（同じ端末で交互に）
- 合法手ヒント、パス通知、最後の一手マーカー
- **戻る**（CPU戦は自分の手＋CPUの応答まで巻き戻す / `Ctrl+Z` / `⌘Z`）
- **譜面**（着手リスト、局面へのジャンプ）
- **レビュー**（全手を前后に再生、盤面見直し）
- 勝敗記録（勝・敗・分と勝率、localStorage 保存）
- 効果音（Web Audio 生成、トグル可）、触覚フィードバック（対応端末）
- テーマ3種（ミッドナイト / クラシック / ウッド）
- レスポンシブ・横画面・矮小画面対応、`prefers-reduced-motion` 対応
- ホーム画面追加（PWAマニフェスト、standalone 表示、オフライン対応）
- 対局中の誤タップ防止（「新しいゲーム」は確認ダイアログ付き）

## 操作

| 操作 | 方法 |
|---|---|
| 石を置く | ヒント（白丸）のマスをタップ / クリック |
| カーソル移動 | 矢印キー |
| 置く（キーボード） | `Enter` / `Space` |
| 戻る | 「戻る」ボタン、`Ctrl+Z` / `⌘+Z` |
| 設定 | 歯車ボタン（難易度・先後・テーマ・音・記録） |

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面構造 |
| `style.css` | スタイル・レスポンシブ・アニメーション |
| `game.js` | ルールとAIの純ロジック（DOM非依存、UMD） |
| `ui.js` | 画面制御（ターン進行・入力・演出） |
| `test.js` | 回帰テスト |
| `manifest.webmanifest` / `icon.*` | PWA（ホーム画面追加） |
| `sw.js` | Service Worker（オフライン対応、初回ロード後にキャッシュ） |

## テスト

```bash
node othello/test.js
```

乱数はシード固定なので、実行のたびに同じ結果になります（サンプリング依存の判定も節ごとにストリームをピン留め済み）。思考予算の検査はCPU時間で測定し、OSのスケジューリングによる誤検知を排除しています。

- 独立実装との照合 6000 盤面（合法手・反転）
- 評価関数の対称性・角/X/C マスの扱い
- zobrist ハッシュの逐次更新と全再計算の一致、5万局面の衝突検査
- 各難易度の適法性と思考時間予算
- 完全探索終盤の最適手検証、強さの相互対局
- ランダム対局の終局検証
